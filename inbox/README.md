# Inbox

Taruh file mentahmu di sini, lalu bilang ke Kiro "inbox sudah diisi". Kiro akan memasukkannya ke situs, mengoptimalkan gambarnya, dan mengecek hasilnya.

| Folder | Isi | Panduan |
|---|---|---|
| `photo/` | 1 foto profil | [photo/README.md](photo/README.md) |
| `certificates/` | gambar sertifikat + `certificates.md` | [certificates/README.md](certificates/README.md) |
| `cv/` | CV versi aman untuk publik | [cv/README.md](cv/README.md) |

Isi folder ini **tidak ikut ke Git** (hanya file README yang ikut), jadi file mentahmu tidak akan terunggah ke GitHub. Yang tampil di situs hanyalah salinan yang Kiro taruh di `public/`.
