# Foto profil

Taruh **satu** foto di folder ini (`.jpg`, `.jpeg`, `.png`, atau `.webp`).

Tips:
- Rasio kotak (1:1) paling pas. Kalau bukan, Kiro akan memotong bagian tengahnya.
- Wajah terlihat jelas, latar sederhana, resolusi minimal 800 x 800 px.
- Nama file bebas.

Kalau ada beberapa foto, tulis di chat mana yang dipakai.
