# Sertifikat

1. Taruh gambar sertifikat di folder ini (`.jpg`, `.png`, atau `.webp`). Satu file per sertifikat.
2. Buat file `certificates.md` di folder ini. Salin format dari `certificates.template.md`.
3. Bilang ke Kiro "inbox sudah diisi".

Data yang dibutuhkan per sertifikat:

| Field | Wajib | Contoh |
|---|---|---|
| `file` | ya | `kaggle-datascience.png` |
| `name` | ya | `Data Science Competition, 1st Place` |
| `issuer` | ya | `TETI Programming Week` |
| `year` | ya | `2025` |
| `link` | tidak | URL verifikasi kredensial, kosongkan kalau tidak ada |
| `alt` | tidak | deskripsi singkat gambar untuk screen reader; kalau kosong Kiro yang menulis |

Catatan privasi: sensor dulu data pribadi yang tidak perlu di gambar, misalnya nomor identitas, nomor sertifikat yang sensitif, atau QR yang membuka data pribadi.
